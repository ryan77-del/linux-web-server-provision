# Provisionamento de Servidor Web com Apache
## 📖 Sobre

Este projeto foi desenvolvido como parte dos estudos de Administração Linux.

O objetivo é automatizar o provisionamento de um servidor web Apache utilizando um script Bash.

O script realiza toda a configuração inicial necessária para disponibilizar um servidor web funcional.

## 🎯 Objetivos

- Automatizar tarefas administrativas
- Praticar Shell Script
- Trabalhar com Systemd
- Instalar e configurar o Apache
- Validar o funcionamento do serviço

## 🛠 Tecnologias

- Linux
- Bash
- Apache2
- Systemd
- APT
